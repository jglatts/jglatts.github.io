Writing a Serial Keyboard Wedge for Windows Part 2

By John Glatts

Something I learned in school was always program to an interface, not an implementation.
In the case of the Serial Keyboard Wedge, the interface is the API we expsose for the serial devices. This allows us to use a number of different devices without having to change the code that uses the API.

The SerialReaderBase API

The SerialReaderBase class is the base class for all serial readers. It defines the API that all serial readers must implement. This includes methods for starting and stopping the reader, as well as an event for when a key is read.
