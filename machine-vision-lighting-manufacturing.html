Interfacing with the AmScope MD310C-BS Using toupcam.dll

By John Glatts

The AmScope MD310C-BS is a compact 3.1MP USB camera used for inspection and measurement systems. It uses a USB interface and comes with a software development kit (SDK) that includes a DLL called toupcam.dll for direct camera control.

Write-Output camera_stack

Camera → toupcam.dll → C# Wrapper → Your App

toupcam.dll

The SDK gives direct access to the camera — exposure, resolution, callbacks — not just a generic webcam feed. It is quite verbose and low-level, but provides the necessary hooks for a custom machine vision application.

Project Setup

  • Add toupcam.cs
  • Copy toupcam.dll next to your .exe
  • Match x86/x64
  • Use wrapper API

Enumerating Cameras

type .\enumerate.cs


                Toupcam.DeviceV2[] arr = Toupcam.EnumV2();

The EnumV2 method is a static method that returns an array of Toupam.DeviceV2 objects. The objects contain the camera's name, type, and a unique identifier. It can be helpful to print this information to the console to verify that your camera is being detected correctly before trying to open it. We use the unique identifier to open the camera later on.

Opening Camera

type .\open.cs


                // note arr is from enumerate step
                Toupcam cam = Toupcam.Open(arr[0].id);

Pull Mode + Callback

type .\callback.cs


                _cam.StartPullModeWithCallback(OnCameraEvent);

The callback is triggered whenever a new frame is available from the camera. It is called in user code, so you can process the frame data directly in the callback function.

Why It Matters

  • Fixed lighting
  • Locked exposure
  • Rigid mounting
  • Calibration

Common Issues

DLL not found → copy next to exe

Camera locked → close vendor app

PullImage fails → check buffer/format

Final Thoughts

Once you can enumerate, open, and pull frames — you have the foundation for a real system. Real-time processing with OpenCV can be layered on top of the camera feed to create a complete machine vision application for manufacturing inspection. It is tricky to get everything working at first, but the SDK provides the necessary tools to build a custom solution that meets your specific needs.
