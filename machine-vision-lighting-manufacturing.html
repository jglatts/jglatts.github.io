Interfacing with the AmScope MD310C-BS Using toupcam.dll

By John Glatts

The AmScope MD310C-BS is a compact 3.1MP USB camera used for inspection and measurement systems.

Write-Output camera_stack

Camera → toupcam.dll → C# Wrapper → Your App

toupcam.dll

The SDK gives direct access to the camera — exposure, resolution, callbacks — not just a generic webcam feed.

Project Setup

  • Add toupcam.cs
  • Copy toupcam.dll next to your .exe
  • Match x86/x64
  • Use wrapper API

Enumerating Cameras

type .\enumerate.cs

var devices = Toupcam.EnumV2();

Opening Camera

type .\open.cs

Toupcam cam = Toupcam.OpenByIndex(0);

Pull Mode + Callback

type .\callback.cs

_cam.StartPullModeWithCallback(OnCameraEvent);

Write-Output pipeline

Why It Matters

  • Fixed lighting
  • Locked exposure
  • Rigid mounting
  • Calibration

Common Issues

DLL not found → copy next to exe

Camera locked → close vendor app

PullImage fails → check buffer/format

Final Thoughts

Once you can enumerate, open, and pull frames — you have the foundation for a real system.
